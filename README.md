# WLMt Token (Testnet) — Walme's Governance & XP Test Token

**WLMt** is the testnet version of the Walme ecosystem token, deployed on the Solana Devnet.

> This token is used solely for testing purposes: governance voting, XP-based airdrops, vesting schedules, and community engagement ahead of the official TGE.
